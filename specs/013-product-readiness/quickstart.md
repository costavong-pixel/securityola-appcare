# Quickstart: 013 Product Readiness

## Required preflight

1. Confirm `TARGET=AppCare`.
2. Confirm repository/branch identity.
3. Run `/saveruflo` read-only preflight.
4. Run `/graphify . --update` and query readiness/release/supportability blast radius.
5. Run Spec Kit constitution/specify/clarify/plan/checklist/tasks/analyze/converge as applicable.

## Implementation acceptance

Run the complete repository deterministic/static/security suite plus new readiness tests proving:

- fixture-only evidence cannot create customer readiness
- one mandatory missing capability blocks stack readiness
- cross-tenant capability evidence is rejected
- stale source/artifact evidence is rejected
- a real-pilot missing capability downgrades dependent readiness
- worker/model self-approval is rejected
- missing pre-beta security evidence blocks launch

Then run:

- Codex Security diff scan
- dependency audit
- secret/public-safety scan
- exact-head GitHub CI
- final Graphify impact review
- Saveruflo checkpoint

No customer production resource is needed or permitted for Spec 013 implementation.
