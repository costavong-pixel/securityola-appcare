## $149/month Protection

For one approved supported application:

- scheduled security scans
- monitoring of key security and availability signals
- off-site backups
- backup health checks
- deployment-change monitoring
- safe fixes when they pass AppCare validation
- rollback/recovery from AppCare-managed backups when applicable
- customer-facing status/reporting

### Not unlimited development

Included fixes must be bounded, security-related, reversible, and pass validation.

Separate quote when work requires:
- major architecture changes
- large feature rewrites
- complex data reconstruction
- unsupported infrastructure
- forensic investigation
- incidents that predate onboarding and cannot be safely bounded
